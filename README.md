# 모듈 파빌리온 (그룹 2)

원소를 발견하거나 직접 골라 결합 규칙대로 3D 파빌리온을 조합하는 정적 웹사이트입니다.

- `index.html` — 파빌리온 조합기 (메인)
- `elements.html` — 원소 주기율표 38개 (치수·결합 규칙)

빌드 과정 없이 폴더째 올리면 됩니다. 3D 라이브러리(three.js r128)는 CDN에서 불러옵니다.

## 로컬에서 보기
폴더에서 `python3 -m http.server` 실행 후 브라우저로 http://localhost:8000

## 구조 규칙 (v0.2)
- **층수 입력**: ③에서 1~8층을 고르면 가장 높은 기둥이 그 층수가 됨 (자동은 기존과 같음)
- **브레이싱**: 3층 이상 기둥은 아래 ⌊층수/2⌋개 층의 바깥면에 가새
  - 층별 차등: 맨 아래층 교차가새 → 그 위층 교차/외가새 번갈아 → 그 위는 한 면 걸러 외가새
  - 통일: 가새가 들어가는 층 전부 교차가새
  - 문·1층 통로·돌출 캡슐이 지나는 면은 무릎가새로 바꿔 통로 확보
- **조인트**: 틀 절점마다 노드, 1층 기둥 밑 베이스 플레이트, 캡슐 밑 받침 레일 + 모서리 앵커, 돌출 캡슐은 레일 끝에서 위 보까지 타이 로드
- **구조만 보기**: 캡슐·바닥을 반투명으로, 파사드·그린을 숨겨 뼈대·가새·조인트만 보이게 함
